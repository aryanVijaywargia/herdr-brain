== 3. PostToolUse and the shell tool
Shell tools: exec_command and write_stdin only (core/src/tools/handlers/shell_spec.rs:96,146).
tool_name = "Bash" for both (unified_exec.rs:92; core/src/tools/hook_names.rs:54-55).
tool_input = {"command": "<cmd string>"} only (core/src/tools/context.rs:398-402; exec_command.rs:251).
  No workdir, no argv.
tool_response = a JSON string with the model-facing output, truncated (context.rs:404-411).
  No exit code, no separate stdout/stderr, no duration. ExecCommandToolOutput holds exit_code and
  wall_time (context.rs:345-360) but does not send them to the hook.
Top-level cwd = turn cwd (hook_runtime.rs:299), not the command workdir.
Long command: exec_command fires no PostToolUse while the process runs (context.rs:405). The write_stdin
  poll that sees the exit fires one PostToolUse (write_stdin.rs:131-139), with tool_use_id = the original
  exec call id, tool_input.command = the original cmd (process_manager.rs:1010-1043), and tool_response =
  only the output of that last poll (process_manager.rs:977-983).
Fires also for a non-zero exit (registry.rs:674-680; context.rs:374-376).
Other tools also fire (registry.rs:95-120, 799-816); apply_patch aliases Write|Edit; MCP own payload.
Matcher: match-all, exact a|b list, or regex (hooks/src/events/common.rs:137-152).

== 4. Stop
Fires at each turn end when no follow-up is needed (core/src/session/turn.rs:552-559): once per turn.
After a blocking Stop hook, the turn continues with stop_hook_active=true and Stop fires again (:571-587).
last_assistant_message: last agent message, null if none (stop.rs:161-163). Matcher ignored
  (hooks/src/engine/dispatcher.rs:70-72).
